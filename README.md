# OmniLoopFixer для Mac

Автоматично знаходить кращий стик у майже зацикленому відео та обрізає зайві кадри. Зберігає **corrected loop** і **Preview ×5** — окремий готовий MP4 із п'ятьма повторами. Обидва файли без звуку. Відео обробляються локально.

**Mac з Apple Silicon, зокрема M1 Pro; macOS 15 або новіша.** Python і FFmpeg уже включені. Intel Mac не підтримується цією збіркою.

## Встановити

1. Відкрийте завантажений DMG.
2. Перетягніть **OmniLoopFixer** у **Applications / Програми**.
3. Запустіть OmniLoopFixer з папки Програми.
4. Виберіть або перетягніть відео, натисніть **Auto Cut + save x5**. Результати за замовчуванням — у `Movies/OmniLoopFixer`.

Це **тестова збірка без Developer ID і нотаризації Apple**. Mac може заблокувати перший запуск. Якщо ви довіряєте цій програмі, після спроби запуску відкрийте **System Settings → Privacy & Security → Open Anyway** і підтвердьте відкриття саме OmniLoopFixer. [Інструкція Apple](https://support.apple.com/en-gb/102445).

Якщо Mac пише про пошкодження або шкідливе ПЗ, зупиніться й передайте точний текст помилки автору. Не вимикайте захист Mac і не запускайте команди для масового видалення quarantine.

## Що перевірено

Збірка на GitHub для arm64 успішно пройшла автоматичні тести: завантаження бібліотеки GUI та drag-and-drop, вбудований FFmpeg, експорт відео й точний п'ятикратний повтор за хешами кадрів. Перевірено цілісність завантаженого ZIP. Запуск на фізичному Mac користувача ще потребує перевірки.

Версія 0.1.0-test: лише Auto Cut; без змішування кадрів, інтерполяції та корекції яскравості. Loop score — порівняльна оцінка алгоритму, а не гарантія непомітного стику.

Цей репозиторій містить інсталятор та інструкції. Репозиторій розробки залишається приватним. Ліцензії сторонніх компонентів і вихідні архіви FFmpeg/x264 включені в DMG.
